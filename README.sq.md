# AvokatIM — agjenti që shpjegon pse (shqip)

Versioni shqip i README-s. Përshkrimi i plotë: docs/hackathon/submission.md.

Agjent ligjor për gjuhën shqipe që nuk jep përgjigje pa burim: dokument, nen, fragment;
kur baza mungon thotë «s'e di» me arsye.

## Numrat (të matur)

| Matja | Vlera |
|---|---|
| Ligji i saktë në vendin e parë | 10/10 |
| Nen i saktë dhe i plotë | 2/10 |
| Neni i duhur brenda top-3 | 7/10 |
| Burim i gabuar në krye | 0/10 |
| Set blind (13 pyetje) | 10/10 brenda, 3/3 refuzuar |

Kufizimi i deklaruar: sistemi gjen ligjin e duhur pothuajse gjithmonë, por nuk zgjedh
gjithmonë nenin që përgjigjet.
